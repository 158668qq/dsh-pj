# Rehydration Plan Schema

`yingan-recovery-plan/v1` is a declarative, hash-bound build input. The builder refuses changed source APKs or DEX files.

```json
{
  "schema": "yingan-recovery-plan/v1",
  "source": {"apk": "C:/work/original.apk", "sha256": "..."},
  "dex": {
    "root": {"path": "C:/work/root-managed.dex", "sha256": "..."},
    "runtime": [{"order": 0, "path": "C:/work/dex_000.dex", "sha256": "..."}]
  },
  "manifest": {
    "application": "com.example.RealApplication",
    "application_selection": "explicit",
    "components": [{"element": "activity", "from": "com.example.ShellActivity", "to": "com.example.RealActivity"}]
  },
  "packaging": {
    "mode": "compatibility",
    "preserve_all_non_dex_entries": true,
    "remove_entries": []
  },
  "verification": {"package": "com.example.app", "launch_activity": "com.example.app/.MainActivity"}
}
```

Rules:

- Use absolute paths and SHA-256 values generated by the supplied tools.
- The first build keeps `remove_entries` empty.
- Every component replacement must use the exact current manifest `android:name` value on the left side.
- A root DEX is optional; when omitted the first runtime DEX becomes `classes.dex`.
- Do not use the plan to alter authorization, credential, or service behavior.
